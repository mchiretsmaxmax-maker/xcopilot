# DeepSeek-исполнитель

DeepSeek — ограниченные «руки». Он не ходит по проекту и не запускает команд: получает задание и перечисленные файлы одним запросом, возвращает полные новые версии файлов. Скрипт `scripts/ds.py` применяет их, гоняет ruff → ruff format → mypy → pytest, при красном даёт до 2 кругов починки и коммитит.

## Что давать DeepSeek

| Давать | Не давать |
|---|---|
| код по готовым тестам и точной сигнатуре | схема БД, миграции, RLS |
| парсеры, нормализация, форматирование текста | деньги: бюджеты, цены, учёт стоимости |
| правила линтера по готовому описанию | безопасность: шифрование, доступ, секреты |
| клавиатуры, тексты бота, роутеры по образцу | промпты писателя и судьи, тесты этапа |
| SQL-файлы метрик по формуле из ТЗ | архитектурные решения, «сделай как лучше» |

## Выбор модели и режима

| Задание | `--model` | `--thinking` |
|---|---|---|
| механика: переименовать, добавить поле, тексты, клавиатуры | flash (точное имя сверить при первом запуске) | нет |
| обычный код по тестам: функция, парсер, правило линтера | `deepseek-v4-pro` (по умолчанию) | нет |
| логика с краевыми случаями: подсчёт длины X, разбор чисел, нарезка | `deepseek-v4-pro` | да |

## Шаблон задания (`docs/tasks/NN-кратко.md`)

```markdown
## Файлы
- src/xcopilot/x/intents.py

## Новые
- (нет)

## Контекст
- tests/unit/x/test_intents.py
- src/xcopilot/x/models.py

## Задача
1. В `x/intents.py` реализуй `weighted_len(text: str) -> int` по правилам X:
   ссылка (http/https) = 23 знака; символы из диапазонов … = 2; остальные = 1.
2. Не меняй другие функции файла. Не добавляй зависимостей.
3. Должны пройти тесты `test_weighted_len_*` из контекста.

## Коммит
feat(x): weighted_len по правилам X
```

Правила задания: точные имена, сигнатуры и что вернуть; какие тесты должны пройти; что трогать нельзя. Один шаг = 1–3 файла. Красный тест, который ломает изменение, — отдельное точное задание.

## После запуска

1. Читать итог (`.ds/RESULT.md`) и `git diff`.
2. Не нравится — новое задание на доработку с цитатой проблемного места.
3. Скрипт коммитит только файлы последнего круга: перед слиянием `git add -A src config tests` и `git commit --amend`.

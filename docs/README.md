## Оценка сроков (13.11.2026)

Темп: оркестратор + сессии-исполнители + DeepSeek на простых шагах, этапы 4/5/6, 8/9, 13/14, 16/17, 18/19, 20/21 идут параллельно.

| Фаза | Этапы | Разработка | С приёмкой на живом аккаунте |
|---|---|---|---|
| 1. MVP | 1–15 | 4–5 недель | 6–7 недель (этап 15 требует 7 дней работы без вмешательства) |
| 2. Развитие | 16–19 | 1,5–2 недели | ещё 3–4 недели (приёмка: неделя, две недели плана) |
| 3. Углубление | 20–21 | ~1 неделя | ещё 2–3 недели (калибровке нужно 100+ решений владельца) |
| **Итого** | 21 | **~2 месяца работы** | **~3–3,5 месяца до конца** |

Для сравнения: один опытный разработчик без ИИ — 6–8 месяцев.

Что может сдвинуть сроки: доступ к Jev (ранний доступ, без него судья временно — DeepSeek); developer app в X и оплата чтения; ключи Anthropic/DeepSeek/TypeSafe; время владельца (примеры постов, 30 постов для eval, подтверждение уроков); версии библиотек и API из ТЗ сверяются на этапах 1 и 4.

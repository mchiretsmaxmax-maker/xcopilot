# FxEmbed (api.fxtwitter.com): что есть и что используем

Проверено 18.11.2026 живыми запросами без ключа (User-Agent `xcopilot/1.0`). Репозиторий: https://github.com/FxEmbed/FxEmbed (MIT, Cloudflare Worker), документация: https://docs.fxembed.com/api/introduction, описание API в машинном виде: `https://api.fxtwitter.com/2/openapi.json`. Лимит API v2: 1000 запросов в минуту с одного IP. Сервис сторонний, без гарантий: при сбое бот работает без этих данных.

## Сейчас в боте

`src/xcopilot/x/public_read.py` ходит в старый адрес v1 `api.fxtwitter.com/{handle}/status/{id}` и берёт текст, автора, дату, лайки, ретвиты, ответы, цитаты, закладки, просмотры и подписчиков автора. Пользуются: `bot/routers/write.py` (`find_post`), `bot/routers/replies.py` («💬 Ответы»), автооценка (ADR 0033). Не берём поля `lang`, `media`, `replying_to`, `community_note`, `card`, `is_note_tweet`.

## Методы v2 (проверка 18.11)

| Метод | Ответ | Заметка |
|---|---|---|
| `/2/status/{id}` | ✅ | объект в ключе `status` (не `tweet`, как в v1) |
| `/2/thread/{id}` | ✅ | `thread` — список частей (на проверочном посте 5) |
| `/2/conversation/{id}` | ✅ | `status`, `thread`, `replies`, `cursor`; вирусный пост 1585841080431321088 → 35 ответов за запрос; у постов с 0–1 ответом пусто |
| `/2/status/{id}/quotes` | ✅ | `results` + `cursor`; 20 за запрос |
| `/2/status/{id}/reposts` | ✅ | владелец решил: не нужно |
| `/2/profile/{handle}` | ✅ | подписчики, подписки, число постов, описание |
| `/2/profile/{handle}/statuses` | ❌ | `{"code":404,"results":[]}` даже для elonmusk — причину выяснить |
| `/2/search?q=…` | ❌ | 404, пусто |
| `/2/trends` | ❌ | 200, но `trends: []` |

Не проверено: как сортируются ответы в `conversation` (по лайкам или по времени), есть ли у каждого ответа свои лайки и просмотры, как листать по `cursor` до 20–30 лучших ответов.

## Запрос владельца (18.11)

1. Подключить в клиент: тред целиком, ответы под постом, цитаты поста, профиль (профиль пока только в клиенте, без использования). Репосты — не нужны.
2. Выяснить, почему лента аккаунта (`/profile/{handle}/statuses`), поиск и тренды пустые: смотреть код FxEmbed (нужен ли вход в X / учётка, ограничение гостевого доступа), можно ли обойти законно (свой экземпляр с учёткой, X API, другой путь).
3. Самообучение на ответах: владелец в «💬 Ответы» кидает пост → бот сам забирает 20–30 самых залайканных ответов (и цитат) под ним → они становятся материалом «вдохновение» формата reply/quote → мозг (brain.detect/extract) извлекает из них приёмы → следующие ответы лучше. Всё автоматически, просто от работы в режиме ответов. Сюда же — учёт выбора владельца из 3 вариантов (обсуждался ранее, план не утверждён).

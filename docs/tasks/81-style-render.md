## Задача
Константу `TG_LIMIT` и сигнатуры не меняй. Реализуй `export_md` и `render`.

1. `export_md(passport, version=None) -> str` — markdown целиком. Первая строка: `# Паспорт стиля` (если `version` не None — `# Паспорт стиля v{version}`), (если `passport.rough` — следующая строка `_Черновой: примеров меньше 5._`). Затем разделы в этом порядке, каждый — строка `## <Название>`, пустая строка, содержимое, пустая строка. Разделы идут ВСЕГДА, даже пустые (пустое содержимое — `—`):
   - `Описание` — `summary`;
   - `Тон` — `tone`;
   - `Лексика` — две строки: `Использовать: a, b` и `Избегать: c, d` (пусто → `—`);
   - `Структура` — строки `Длина: …`, `Переносы: …`, `Зачины: a; b`, `Концовки: a; b`;
   - `Форматы` — маркированный список `- short: 80%` (`round(share*100)`);
   - `Жёсткие правила` — маркированный список: `- Регистр: только строчные` (casing lower) или `- Регистр: любой`; `- Эмодзи: нет` (none) / `редко` (rare) / `свободно` (free); `- Хэштеги: …` и `- Ссылки: …` так же; `- Длина: до {max_len} знаков`; для каждой фразы из `banned_phrases` — `- Запрет: «{фраза}»`;
   - `Фирменные приёмы` — маркированный список `signature_patterns`;
   - `Примеры` — нумерованный список `1. {text}`;
   - `Анти-примеры` — маркированный список;
   - `Доказательства` — маркированный список `- {claim}: {id1}, {id2}`.
   Пустой список → одна строка `—`.
2. `render(passport, version=None) -> list[str]` — тот же текст для Telegram, разрезанный на части длиной не больше `TG_LIMIT` (4096) знаков:
   - взять `export_md(...)`, резать по границам: сначала по пустым строкам (блоки), блоки накапливать в часть, пока `len(часть) + 2 + len(блок) <= TG_LIMIT`;
   - блок длиннее лимита резать по строкам; строку длиннее лимита — по символам;
   - пустых частей нет; ничего не теряется (склейка частей через `\n\n` / `\n` даёт те же слова);
   - паспорт, влезающий в лимит, возвращается одной частью.
3. Не добавляй зависимостей. Должны пройти оба теста из `tests/unit/style/test_render.py`.

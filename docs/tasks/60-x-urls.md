## Задача
1. В `x/models.py` реализуй только свойство `PostRef.url -> str` (остальное в файле не меняй):
   - есть `handle` → `f"https://x.com/{handle}/status/{id}"`;
   - `handle is None` → `f"https://x.com/i/web/status/{id}"`.
2. В `x/urls.py` реализуй три функции (сигнатуры и docstring не меняй, зависимостей не добавляй, только `re` из стандартной библиотеки):
   - Общий скомпилированный regex поста `_POST_RE` (флаг `re.IGNORECASE`), ищется в любом месте текста:
     необязательная схема `https?://`, необязательный поддомен `www.` или `mobile.`, домен `x.com` или `twitter.com`,
     затем `/` и либо хэндл `(?P<handle>[A-Za-z0-9_]{1,15})`, либо `i` или `i/web`; затем `/status/` или `/statuses/`
     и id `(?P<id>\d{1,20})`, за которым НЕ идёт цифра или буква (`(?![0-9A-Za-z])`). Перед доменом не должно быть
     буквы, цифры, точки или `/` (`(?<![\w./])`), чтобы не ловить `notx.com`. Хвост (`?s=20`, `/photo/1`) не важен.
     Если хэндл равен `i` (без учёта регистра) — `handle=None`.
   - `parse_post_url(text) -> PostRef | None`: первое совпадение `_POST_RE` → `PostRef(id, handle)`; нет — `None`.
   - `extract_post_urls(text) -> list[PostRef]`: все совпадения по порядку; повтор того же `id` пропускать.
   - `parse_handle(text) -> str | None`:
     а) `s = text.strip()`; пусто → `None`;
     б) если `s` совпадает с началом ссылки на профиль (`(?:https?://)?(?:www\.|mobile\.)?(?:x|twitter)\.com/` без учёта
        регистра) — взять первый сегмент пути после домена (до `/`, `?`, `#` или конца); если сегмента нет → `None`;
        иначе если это ссылка, не начинающаяся с домена x.com/twitter.com (например `https://example.com/...`) → `None`
        (то есть строку с `://` или с `.` в первом токене, не являющуюся ссылкой X, отвергай);
     в) иначе снять один ведущий `@`;
     г) результат должен целиком соответствовать `[A-Za-z0-9_]{1,15}`, иначе `None`;
     д) зарезервированные имена (без учёта регистра) → `None`: `i`, `home`, `explore`, `search`, `settings`,
        `messages`, `notifications`, `intent`, `share`, `hashtag`, `login`, `signup`, `tos`, `privacy`.
     Возвращай хэндл в исходном регистре.
3. Должны пройти все тесты из `tests/unit/x/test_urls.py`.

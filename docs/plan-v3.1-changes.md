## Согласующие правки (не новые требования)

Сделаны, чтобы текст этапа не противоречил удалённым `lessons` и референсам. Проверить при приёмке:

- Этап 9: порядок урезания без «референсов» (антипримеры → факты → примеры до минимума 4); раздел знаний урезается внутри 9B.
- Этап 7: тест `test_source_kind_question_defaults_to_tagger_guess` заменён на `test_source_relation_question_defaults_to_inspiration` (дельта задаёт «Нравится» по умолчанию).
- Этап 10: «кэшируемые блоки: инструкции, паспорт, уроки» → без уроков; тест `test_passport_and_lessons_blocks_cacheable` → `test_passport_block_cacheable`; вход предложения тем — «рабочие знания» вместо «уроков».
- Этап 17: глобальный слой — знания, а не уроки (`promote_to_global(item_id, …)`); условие переноса — подтверждение на своих постах минимум в двух аккаунтах и одобрение администратора (Б8.3).
- Этап 10, критерий «≤ $0.15»: на подписке стоимость вызова 0, считается по токенам.

## Не решено в v3.1 (нужен ответ главного чата)

- Метрика `lessons_accepted_week` (этап 3, 17 метрик) и события `lesson.proposed / accepted / rejected` остались в списках этапа 3, а таблицы `lessons` нет. v3.1 про них молчит. Предложение для ретрофита: считать по `knowledge.owner_decision`; события `lesson.*` не использовать.
- Этап 20: файл `autotune/lesson_weights.py` и тест `test_lesson_weights_follow_effect` сохранили имена v3; по смыслу — веса знаний.

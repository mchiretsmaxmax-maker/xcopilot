# ADR-0013: Ретривал (этап 9)

Статус: принято (этап 9, 14.11.2026).

## Контекст
Писателю нужен воспроизводимый контекстный пакет по теме за < 300 мс (p95, 50 тыс. кусков):
паспорт, примеры голоса, уроки, факты, антипримеры, референсы — в рамках токен-бюджета.

## Решения
1. **Без миграции.** В схеме уже есть HNSW `ix_embeddings_vec_hnsw` (косинус, m=16,
   ef_construction=64) и GIN `ix_chunks_tsv` по `tsvector('simple')`. Уникальные индексы
   `(account_id, chunk_id, model_id)` и `(account_id, document_id, idx)` покрывают соединения.
2. **SQL только в `xcopilot.db`** (тест слоёв): `db/repos/retrieval.py::RetrievalRepo`;
   `retrieval/search.py` — чистая логика (RRF, MMR) и тонкие обёртки над репозиторием.
3. **Видны только куски готовых источников** (`sources.status = 'indexed'`), только своего
   аккаунта и только векторы активной модели `embedding_models`.
4. **Вектор:** `ORDER BY vec <=> :q LIMIT n` с соединениями и фильтрами в одном запросе;
   `hnsw.iterative_scan = relaxed_order` (pgvector 0.8), иначе фильтр по аккаунту/виду после
   индекса недобирал бы строки; `hnsw.ef_search = max(100, 2·limit)`. Порядок внутри
   результата добивается в Python по `(score ↓, chunk_id)`.
5. **Полнотекст:** слова запроса (`\w+`, нижний регистр) через ИЛИ в `to_tsquery('simple', …)`;
   вводимый текст никогда не попадает в синтаксис tsquery. Ранг — `ts_rank_cd`.
6. **RRF** `k=60`; ничья — по `chunk_id`. **MMR** `λ=0.7`: релевантность = score / max,
   сходство — косинус векторов (без вектора — Жаккар по словам). Кандидатов
   `max(4k, 40)` с каждого поиска.
7. **Секции пакета.** Голос — только `own_post`; референсы — `liked_sample` и
   `competitor_post` (отдельная секция); `note/file/chat` в пакет не идут. Уроки — принятые
   своего аккаунта и аккаунта `global`, по весу (до 20). Факты — `expires_at IS NULL OR > now`,
   новее — раньше, до 10. Антипримеры — первые 2 из `anti_examples` паспорта.
8. **Паспорт** читается как JSON через `PassportsRepo` (`xcopilot.style` не импортируется,
   договорённость с этапом 8): `hard_rules` берётся из тела, иначе из колонки.
9. **Токены:** `estimate_tokens = max(1, ⌈знаков/3⌉, слов)` — завышает осознанно.
10. **Урезание** до бюджета (по умолчанию 6000), по одному элементу с хвоста: антипримеры →
    референсы → факты → примеры до 4. Паспорт, правила и уроки не урезаются; если и
    так не влезло — предупреждение `over_budget`. Что урезано — `ContextPack.trimmed`.
11. **Воспроизводимость.** `generation_runs.context_pack` = `PackIds` (id кусков, уроков,
    фактов, id паспорта, число антипримеров, предупреждения). `rehydrate` читает тексты по id
    и даёт побайтно тот же `ContextPack`, даже если факт уже истёк. Поэтому в `PackFact` нет
    срока годности — он проверяется при сборке.
12. **События:** `retrieval.pack_built` (счётчики секций, токены, бюджет, число урезанного) —
    в конец `metrics/events.py`; `/why` пишет `user.action`.
13. **`/why`** показывает последний запуск аккаунта: примеры, уроки, факты, антипримеры,
    референсы (каждый до 80 знаков), версию паспорта и промпта (`ключ vN`).
14. **Тест индекса** (`explain_vector_search`) выключает seq scan, bitmap и явную сортировку:
    на малой таблице планировщик иначе не выберет HNSW; проверяется, что запрос способен
    его использовать.

# ADR-0005: процесс TDD

Статус: принято (этап 1).

## Контекст
Работу ведут AI-исполнители; нужен механический способ не дать им «подогнать тест под код».

## Решение
1. Один этап = одна ветка `stage/NN-имя` = один PR.
2. Первые коммиты — только тесты этапа и пустые заглушки; коммит помечается тегом `stage-NN-red`.
3. Исходные тесты не меняются. Неверный тест исправляется отдельным коммитом `test-fix:` с объяснением в PR.
4. `scripts/check_tdd.sh` в CI проверяет по всем тегам `stage-*-red` в истории: тест не удалён и не пропущен (`skip`, `skipif`, `xfail`, `pytestmark`, `pytest.skip()`).
5. Этап закрыт, когда зелёные все тесты и выполнен общий критерий готовности (покрытие ≥ 85%, ruff, mypy --strict).
6. Не прошло — merge запрещён; в PR заполняется таблица «Что чинить».

## Последствия
- Удалённый или пропущенный тест блокирует CI.
- Красный коммит `stage-NN-red` обязателен и виден в истории.

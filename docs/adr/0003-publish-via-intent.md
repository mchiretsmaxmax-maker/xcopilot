# ADR-0003: публикация только через Intent и решение человека

Статус: принято (этап 1).

## Контекст
Бот не должен публиковать в X сам: ошибка или манипуляция текстом (prompt injection) недопустимы в публичном канале.

## Решение
Любое действие в X описывается явным объектом **Intent** (создать пост, ответить, лайк…). Код готовит и проверяет Intent (линтер, судья, политики), а выполняет его только после явного подтверждения человека кнопкой в Telegram. Подтверждение привязано к конкретной версии текста; правка после подтверждения сбрасывает его.

## Последствия
- Автопубликации нет ни в каком режиме.
- Каждый шаг пишет событие в `events`: видно, кто и что решил.
- Чужой текст (твиты, файлы) считается недоверенным и не может создавать Intent.

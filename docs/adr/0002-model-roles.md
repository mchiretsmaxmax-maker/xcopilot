# ADR-0002: роли моделей

Статус: принято (этап 1).

## Контекст
Разные задачи требуют разного качества и цены: письмо текста, дешёвая массовая разметка, независимая оценка.

## Решение
Роли жёстко разделены и вызываются только через единый шлюз `llm/gateway`:
- **writer** — Claude (Anthropic): пишет посты и ответы;
- **cheap** — DeepSeek (OpenAI-совместимый API): классификация, разметка, извлечение признаков;
- **judge** — Jev (TypeSafe): независимый судья черновиков.
Модель, цена и лимиты задаются в `config/models.toml` и `config/pricing.toml`, а не в коде. Дневные лимиты расходов (`LLM_DAILY_LIMIT_USD`, `X_DAILY_LIMIT_USD`) жёсткие: превышение — `BudgetExceeded`.

## Последствия
- Судья не пишет текст, писатель не судит: нет самооценки.
- Смена модели — правка конфига, не кода.
- В тестах роли заменяются подделками `FakeLLM`/`FakeJudge`.

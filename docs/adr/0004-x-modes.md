# ADR-0004: режимы доступа к X

Статус: принято (этап 1).

## Контекст
Доступ к X API платный и ограниченный; нужны и чтение, и публикация, и контроль расходов.

## Решение
Интеграция с X изолирована интерфейсом `x/client` с взаимозаменяемыми режимами: официальный API v2 (с токенами владельца, хранятся зашифрованно Fernet-ключом `SECRETS_KEY`), oEmbed для публичных твитов без ключей и подделка `FakeX` для тестов. Режим выбирается конфигурацией аккаунта. Каждый вызов учитывается в стоимости (`x/cost`) и ограничен `X_DAILY_LIMIT_USD`.

## Последствия
- Бот работает с урезанными возможностями и без платного API.
- Нет обращений к X мимо клиента — это проверяется тестами.
- Смена режима не затрагивает остальной код.

# ADR 0014 — Паспорт стиля (этап 8)

Статус: принято (14.11.2026).

## Решения

1. **Хранение без миграций.** `style_passports.body` — весь паспорт (`StylePassport`, имена ключей по договорённости с этапом 9: `summary, tone, lexicon, structure, formats, hard_rules{casing,emoji,hashtags,links,max_len,banned_phrases}, signature_patterns, examples, anti_examples, evidence, rough`). Колонка `hard_rules` — плоский список `{name, value}` (+ `banned_phrase`) для проверок кодом. `source_refs` — id кусков из доказательств и примеров.
2. **Жёсткие правила только из статистики.** `derive_hard_rules(stats)`: строчные — доля ≥ 90%; эмодзи/хэштеги/ссылки — доля постов ≤ 10% → `none`, ≤ 40% → `rare`, иначе `free`; `max_len` = 280, если p90 ≤ 280, иначе p90·1,1 (потолок 25 000). Ответ модели с `hard_rules` игнорируется; от модели берутся только запреты фраз — и только с доказательствами. Доли форматов тоже считаются кодом (по меткам `format:`).
3. **Доказательства обязательны.** Утверждение модели (лексика, запреты, приёмы) без id кусков своего голоса отбрасывается; чужие и несуществующие id отфильтровываются. Примеры — только собственные посты (`sources.kind = own_post`, `status = indexed`).
4. **Выборка**: по кругу по форматам (метка `format:`), новые первыми, пока влезают в токен-бюджет (`count_tokens`, по умолчанию 6000). Статистика считается по всем (до 500) собственным постам, а не по выборке. Меньше 5 постов → `rough = true`.
5. **Версии.** Новая версия всегда `draft`; `activate` архивирует прежнюю активную; `rollback` активирует ближайшую более раннюю архивную. Откат — кнопка «Откатить к vN» в истории.
6. **Правки владельца** создают черновик `created_by=user` и не активируются сами. Основа правки — «рабочая» версия: непринятый пользовательский черновик новее активной (правки копятся), иначе активная, иначе последняя. Нумерация «убери правило N» — `list_rules`: правила, отличные от умолчаний, затем запреты; убрать переключатель = вернуть умолчание.
7. **События**: новых типов нет — `passport.created`, `passport.activated` (в т.ч. при откате) и `user.action` (`menu.style`, `style.rules/examples/history/rebuild/export/activate/keep/rollback/toggle/ban/unrule`).
8. **Анти-AI пакет v1**: `style/seed/anti_ai_{ru,en}.yaml` → уроки системного аккаунта `global`, `status=accepted`, идемпотентно по тексту (`load_seed(session)`); вызвать при старте приложения (пока воркер/запуск не собраны — не подключено).
9. **Промпт** `style.extract.v1` — роль `writer`, посты оборачиваются `wrap_untrusted` с label `chunk_<id>`.
10. **Бот**: роутер `style` включён раньше `menu` (перехватывает `menu:style`); `BotDeps.style: StyleService | None`.

## Не сделано / дальше
- Приёмка на 10 настоящих постах владельца; eval `test_eval_passport_stability` (маркер `eval`) на настоящей модели.
- Подключение `StyleService` и `load_seed` в сборке приложения (вместе с воркером).

# ADR 0035 — Писатель через Codex CLI

Статус: принято. Заменяет [ADR 0011](0011-subscription-writer.md).

Роль `writer` использует `codex exec` с авторизацией ChatGPT. GPT‑6.2 Sol с усилием `medium` — общий профиль для черновиков, переписывания и извлечения знаний. Модель задаётся в `config/models.toml`, усилие, путь, таймаут и параллельность — в переменных `CODEX_CLI_*`. Судья и дешёвая роль работают через существующие маршруты DeepSeek.

Провайдер отправляет запрос через stdin, а инструкции передаёт отдельным файлом в закрытой временной папке. Запуск эфемерный, с песочницей read-only и отключёнными инструментами оболочки, браузинга, приложений и плагинов. CLI получает ограниченный набор переменных окружения для запуска и входа. Вывод пользователя и диагностика CLI не попадают в тексты ошибок. Шлюз проверяет результат по существующей JSON-схеме и при необходимости запрашивает одну починку. Ограничение `max_tokens` в интерфейсе шлюза участвует в оценке бюджета. У `codex exec` нет параметра для установки жёсткого лимита вывода на вызов.

Последнее сообщение и токены берутся из JSONL. API-стоимость в `llm_calls` для `codex_cli` равна нулю, запросы используют лимит или кредиты ChatGPT. Исчерпание лимита обрабатывается как временная недоступность, отсутствие входа — как ошибка настройки. Существующие записи, стоимость и черновики в БД сохраняются.

Для локальной установки бот работает на хосте под пользователем, выполнившим `codex login`, а PostgreSQL остаётся в Docker. Проверка только писателя: `python -m xcopilot.llm ping writer` при загруженной конфигурации. См. [runbook](../runbook.md) и [документацию Codex exec](https://learn.chatgpt.com/docs/non-interactive-mode).
